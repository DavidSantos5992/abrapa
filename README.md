# ABRAPA Jundiaí

Site institucional da Associação Brasileira de Apoio aos Portadores de Aids,
com foco em acolhimento, apoio social, projetos, campanhas, doações e contato
com pessoas de Jundiaí e região.

## Desenvolvimento

```bash
npm install
npm run dev
```

Verificações disponíveis:

```bash
npm run build
npm run lint
```

O conteúdo editorial e os dados de contato devem ser conferidos nas fontes
oficiais antes de qualquer publicação: <https://abrapajundiai.org.br/> e
<https://www.instagram.com/abrapa_jundiai/>.
